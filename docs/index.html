Scope

What is verified and what is not

Verified

  • Routing, bounds and trace across all four levels, offline and live
  • Local analyzers against known answers, e.g. #777777 on white = 4.48:1
  • OSV.dev and GitHub Actions calls return live data
  • Honest failure paths: UNAVAILABLE and INPUT NEEDED

Not yet verified

  • Postgres and AWS IAM tools against real systems (tested with simulated responses only)
  • Answer quality: there is no graded golden set or repeated-run consistency check yet
  • Service concerns: the Streamlit UI has no authentication; no HTTP API, tracing or enforced cost ceiling
